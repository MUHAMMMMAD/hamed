# 🏗️ MASARAT AI — COST INTELLIGENCE PLATFORM
### منصة مسارات الذكية لتسعير ودراسة المناقصات | شركة مسارات التشييد

> **مجلس ذكاء اصطناعي متعدد النماذج (Multi-LLM Council)** يجمع ثمانية نماذج داخل
> محرك واحد، مع محرك تسعير حقيقي، محرك مخاطر، قرار Bid/No-Bid، وتدفقات نقدية.

هذا **نظام فعلي قابل للتشغيل الآن** (Python) — وليس ملف Excel فقط. يعمل بالكامل
في "الوضع التجريبي" بدون أي مفاتيح، ويتحوّل إلى التحليل الحقيقي بمجرد إضافة
مفاتيح الـ API.

## ⚡ تشغيل سريع (3 خطوات)

```bash
# 1) تثبيت المتطلبات
pip install -r requirements.txt

# 2-أ) لوحة الويب (الأسهل): واجهة رسومية كاملة
python -m masarat serve
#     ثم افتح http://127.0.0.1:8000/

# 2-ب) أو سطر الأوامر: تحليل كامل على مشروع نموذجي (مبنى إداري)
python -m masarat demo

# 3) النتيجة: تقرير تنفيذي + ملف Excel + تقرير Markdown في مجلد output/
```

لا تحتاج أي مفاتيح للبدء — النظام يعمل فوراً في الوضع التجريبي.

### 🖥️ لوحة الويب
واجهة رسومية عربية (RTL) تتيح: تشغيل النموذجي، **رفع جدول كميات (Excel/CSV)
وتحليله تلقائياً**، تنزيل القوالب، **إدخال أسعارك الفعلية**، مداولة المجلس،
وتنزيل ملف Excel الكامل — كل ذلك من المتصفح.

## 🤖 الوكلاء الذكيون الثمانية (Agents)

يمرّ كل مشروع على فريق وكلاء بالترتيب التالي (التبعيات محسوبة):

```
هندسة → مشتريات → مخاطر → تسعير → قانوني → مناقصة → PMO → CEO
```

1. **Engineering Agent** — تحليل البنود والمخططات والبنود الحرجة.
2. **Procurement Agent** — أسعار الموردين والبنود طويلة التوريد واتجاهات السوق.
3. **Risk Agent** — مصفوفة مخاطر (سوق/تنفيذ/عقد/موردون/وقت) + معامل تعديل.
4. **Estimation Agent** — محرك التسعير الكامل.
5. **Legal Agent** — مراجعة العقد والمخاطر القانونية (Claude).
6. **Tender Agent** — قرار Bid / No-Bid + احتمال الفوز.
7. **PMO Agent** — التدفقات النقدية وخطة التنفيذ.
8. **CEO Agent** — القرار النهائي والتقرير التنفيذي.

## 🧮 محرك التسعير (Pricing Engine)

يحوّل جدول الكميات من "جدول" إلى **محرك تسعير حي** عبر تحليل السعر لكل بند:

```
تكلفة الوحدة = Σ (معامل المورد × سعر المورد)
التكلفة المباشرة = مواد + عمالة + معدات + مقاولو باطن
إجمالي التكلفة   = مباشرة + مصاريف 10% + احتياطي 15% + معامل المخاطر
سعر البيع        = إجمالي التكلفة + ربح 15%
السعر النهائي    = سعر البيع + ضريبة 15%
```

> **تحقق ذاتي مدمج:** صافي التراكم النهائي في التدفقات النقدية = الربح تماماً،
> مما يثبت اتساق محركي التسعير والتدفقات.

## 📊 المخرجات

عند تشغيل التحليل تحصل على:

- **تسعير كامل**: تكلفة مباشرة، سعر بيع، هامش ربح، تفصيل لكل بند.
- **تحليل مخاطر**: جدول مخاطر مفصّل + معامل تعديل.
- **قرار تنفيذي**: BID / NO-BID / BID WITH CONDITIONS + درجة + احتمال فوز.
- **تدفقات نقدية**: شهرية + أقصى تمويل مطلوب.
- **ملف Excel احترافي** (6 أوراق) + **تقرير Markdown** في مجلد `output/`.

## 🖥️ الاستخدام

### سطر الأوامر (CLI)
```bash
python -m masarat serve                    # تشغيل لوحة الويب + الـ API
python -m masarat demo                      # تحليل كامل على المشروع النموذجي
python -m masarat status                    # حالة النماذج الثمانية
python -m masarat prices                    # عرض قواعد الأسعار
python -m masarat analyze tender.json       # تحليل مناقصة من ملف JSON
python -m masarat import-boq boq.xlsx       # استيراد وتحليل BOQ من Excel/CSV/PDF
python -m masarat read-dxf drawing.dxf      # قراءة رسم هندسي DXF
python -m masarat template boq              # توليد قالب جدول كميات
python -m masarat template prices           # توليد قالب الأسعار (مُعبّأ)
python -m masarat import-prices prices.xlsx # إدخال أسعارك الفعلية للنظام
python -m masarat council "سؤالك هنا"       # مداولة جماعية بين النماذج
```

### 📥 قارئ جداول الكميات التلقائي (BOQ Auto-Reader)
يقرأ ملفات **Excel (.xlsx)** و**CSV** و**PDF** بترويسات عربية أو إنجليزية،
ويكتشف الأعمدة آلياً (الكود/الوصف/الوحدة/الكمية/سعر الوحدة...)، ويتخطّى صفوف
العناوين والإجماليات. يدعم الجداول المُسعّرة مسبقاً (سعر وحدة إجمالي) أو
المُفصّلة (مواد/عمالة/معدات/مقاول باطن لكل وحدة).

### 📐 قراءة الرسومات الهندسية (DXF)
```bash
python -m masarat read-dxf drawing.dxf
```
يستخرج الطبقات، عدّ الكيانات، النصوص (الوسوم/الأبعاد)، أطوال الخطوط،
ومساحات المضلّعات المغلقة — كمساعدة لحصر الكميات. (لملفات DWG صدّرها إلى DXF.)

### 🧠 محرك التعلّم الآلي (Cost Intelligence)
يتعلّم من **انحرافات مشاريعك السابقة** (انحدار خطي) فيتنبّأ بانحراف المشروع
الجديد، ويعاير **الاحتياطي وهامش الربح** تلقائياً. كلما أدخلت مشاريع منفّذة
أكثر، ارتفعت دقة التسعير نحو 95–98%.

### 🗂️ إدخال بياناتك الفعلية (Real Data Entry)
```bash
python -m masarat template prices           # 1) نزّل القالب (مُعبّأ بالحالي)
# 2) عدّل القيم بأسعارك/مورديك/مشاريعك الفعلية في output/PRICES_template.xlsx
python -m masarat import-prices output/PRICES_template.xlsx   # 3) استورد
```
أو افعل ذلك كله من لوحة الويب (تبويب «بياناتي الفعلية»). تُحدَّث قاعدة بيانات
النظام فوراً وتُستخدم في كل التحليلات التالية.

### واجهة برمجية (REST API)
```bash
uvicorn masarat.api:app --reload
# ثم افتح: http://127.0.0.1:8000/docs
```

| المسار | الوصف |
|---|---|
| `GET /` | لوحة الويب (الواجهة الرسومية) |
| `GET /providers` | حالة النماذج الثمانية |
| `GET /prices` | قواعد الأسعار |
| `GET /demo` | تحليل المشروع النموذجي |
| `POST /analyze` | رفع مناقصة (BOQ JSON) والحصول على التحليل |
| `POST /analyze/excel` | رفع مناقصة والحصول على ملف Excel |
| `POST /ui/analyze` | رفع ملف BOQ (Excel/CSV) وتحليله تلقائياً |
| `GET /templates/boq` · `GET /templates/prices` | تنزيل القوالب |
| `POST /ui/import-prices` | استيراد الأسعار الفعلية |
| `POST /council` | مداولة جماعية بين النماذج |

### كمكتبة Python
```python
from masarat.database import load_sample_tender
from masarat.pipeline import analyze_tender
from masarat.reports import build_report, export_excel

analysis = analyze_tender(load_sample_tender())
print(build_report(analysis))
export_excel(analysis, "cost_sheet.xlsx")
```

## 🌐 النشر كموقع برابط دائم

يأتي النظام بنسختين (التفاصيل في **[`deploy/DEPLOY.md`](deploy/DEPLOY.md)**):

**① النسخة الثابتة (`static/index.html`) — تعمل على cPanel/أي استضافة بلا Python.**
محرّك التسعير/المخاطر/القرار/التدفقات/التعلّم يعمل **داخل المتصفح**. ارفع الملف
الواحد إلى مجلد نطاقك الفرعي وانتهى. أعد بناءه بعد تعديل الأسعار عبر:
`python tools/build_static.py`.

**② نسخة الخادم (Python/FastAPI) — النظام الكامل** (يضيف مجلس نماذج الذكاء
الحيّ و API ومشاركة البيانات). الأسهل عبر **Render** (اربط المستودع — يكتشف
`render.yaml`)، أو على **خادم VPS (Docker):**

```bash
# على خادم Ubuntu (بعد تثبيت Docker)
git clone https://github.com/MUHAMMMMAD/hamed.git && cd hamed
git checkout claude/gallant-cerf-aq45eq
bash deploy/deploy.sh          # يبني ويشغّل التطبيق + Nginx
# ثم افتح:  http://<عنوان-الخادم>/
```

يشمل الإعداد: **Docker Compose** (تطبيق + **Nginx** وكيل عكسي على المنفذ 80)،
وخدمة **systemd** كبديل بدون Docker، ودعم **HTTPS** عبر Let's Encrypt، وحفظ
بياناتك في `data/seed` و`output`. التفاصيل الكاملة خطوة بخطوة في:
**[`deploy/DEPLOY.md`](deploy/DEPLOY.md)**.

## 🎯 الواقعية في الدقة (مهم جداً)

لا يضمن أي نظام دقة **99.99%** قبل التنفيذ (ولا حتى Bechtel أو Fluor)، بسبب
متغيرات لا تُعرف مسبقاً (أسعار، أوامر تغيير، ظروف موقع، إنتاجية فعلية...).
الهدف **الواقعي** المتدرّج:

| المرحلة | الدقة | كيف |
|---|---|---|
| الأولى ✅ (هذه النسخة) | 80–90% | BOQ + قاعدة أسعار + تحليل سعر |
| الثانية | 90–95% | أسعار موردين فعلية + عروض مقاولي باطن |
| الثالثة | 95–98% | بيانات تاريخية + تعلّم آلي من المنفّذ |

**التوصية:** استهدف دقة 99% في *حصر الكميات*، و95%+ في *الأسعار*، مع تحليل
مخاطر آلي — عندها يصبح التسعير واقعياً وتنافسياً ومربحاً.
