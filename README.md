# مسارات التشييد — الموقع الرسمي

موقع شركة **مسارات التشييد للمقاولات**، مبني بـ Next.js وواجهة عربية RTL بالكامل،
ومزوّد بمنصة ذكاء اصطناعي تعمل على قاعدة معرفة الشركة ومحرك تقدير هندسي.

---

## أدوات الذكاء الاصطناعي

| الأداة | المسار | ما تفعله |
| --- | --- | --- |
| **المساعد الذكي** | أيقونة المحادثة في كل صفحة | إجابات متدفقة (streaming) عن الأسعار والمدد والخدمات والضمانات |
| **حاسبة التكلفة الذكية** | `/ai#estimator` | تقدير تكلفة بتوزيع البنود وجدول الدفعات والمخاطر وفرص التوفير |
| **مولّد نطاق العمل** | `/ai#scope` | وثيقة نطاق عمل بمراحل وتسليمات وجدول كميات مبدئي، قابلة للتحميل |
| **تحليل صور المواقع** | `/ai#vision` | فحص بصري لصورة موقع البناء: مرحلة الإنجاز والسلامة والجودة |

### مبدأ التصميم: الأرقام تُحسب، والنموذج يشرح

حاسبة التكلفة **لا تطلب من النموذج اختراع أرقام**. المحرك الحسابي في
`src/lib/estimator.ts` يحسب التكلفة والمدة وتوزيع البنود من معاملات هندسية
(نوع المشروع، مستوى التشطيب، معامل المدينة، عدد الأدوار، وفورات الحجم)، ثم
يُمرَّر الناتج إلى النموذج ليشرحه ويستخرج المخاطر والتوصيات. هذا يمنع تضارب
الأرقام بين ما يُعرض وما يُذكر في التحليل.

### النظام الاحتياطي

كل مسار ذكاء اصطناعي له بديل محلي في `src/lib/fallback.ts`:

- **بلا مفتاح API** أو عند فشل الاتصال، يستمر الموقع في العمل: التقدير يعتمد
  على المحرك الحسابي وحده، والمحادثة تُجيب من قاعدة معرفة الشركة بمطابقة نصية.
- تُظهر الواجهة شارة توضّح مصدر النتيجة (`تحليل بالذكاء الاصطناعي` أو `المحرك المحلي`).
- **تحليل الصور وحده** يتطلب المفتاح، ويعيد رسالة واضحة بدونه.

## التشغيل

```bash
npm install
cp .env.example .env.local   # ثم أضف ANTHROPIC_API_KEY
npm run dev                  # http://localhost:3000
```

للإنتاج:

```bash
npm run build && npm start
```

### متغيرات البيئة

| المتغير | إلزامي | الوصف |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | لا | يفعّل محركات الذكاء الاصطناعي. بدونه يعمل الموقع بالمحرك الاحتياطي. |
| `ANTHROPIC_MODEL` | لا | الافتراضي `claude-opus-5`. |
| `CONTACT_INBOX` | لا | بريد استقبال طلبات عروض الأسعار (نقطة ربط مستقبلية). |

│       └── contact/          استقبال طلبات عروض الأسعار

    ├── company.ts            قاعدة معرفة الشركة — مصدر واحد للحقيقة

    └── format.ts             تنسيق الأرقام العربية-الهندية

### قاعدة معرفة واحدة

`src/lib/company.ts` هو المصدر الوحيد لبيانات الشركة: يُغذّي صفحات الموقع
**ويُحقن في موجّه النظام** لكل استدعاءات الذكاء الاصطناعي. تعديل خدمة أو مشروع
أو رقم هاتف في هذا الملف ينعكس على الصفحات وعلى إجابات المساعد معاً، فلا
يحدث تضارب بين ما يُعرض وما يُقال.

## ملاحظات فنية

- **التقنيات**: Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS 4 + Anthropic SDK.
- **الأرقام**: كل رقم ظاهر يمرّ من `src/lib/format.ts` لضمان اتساق الأرقام
  العربية-الهندية (باستثناء حقول `input[type=number]` وأرقام الهواتف).
- **الخطوط**: تُحمَّل من المتصفح لا وقت البناء، فلا يفشل البناء في بيئة بلا شبكة.
- **الأمان**: كل مدخلات الـ API تُتحقَّق بـ Zod، ورفع الصور محدود بالصيغة
  (JPG/PNG/WEBP) والحجم (٥ ميجابايت).
- **التحقق**: `npm run typecheck` للأنواع، و`npm run build` للبناء الكامل.

## قبل النشر

البيانات التالية في `src/lib/company.ts` عناصر نائبة يجب استبدالها ببيانات
الشركة الفعلية: `phone`، `whatsapp`، `email`، `crNumber`، `vatNumber`، `address`.
كما أن `src/app/api/contact/route.ts` يسجّل الطلبات في السجل فقط — اربطه بمزوّد
بريد أو نظام CRM قبل التشغيل الفعلي.
